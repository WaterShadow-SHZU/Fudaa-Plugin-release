# 定标包与表面流速 CSV（摘录）

与 Canal 派端 `canal calib install`、平台表面流速导入对齐。实现以代码与派端校验为准。

## 定标包

平铺：`GRP.dat`、`img_ref.dat`、`PIV_param.dat`、`grid.dat`、`h.dat`、`site.json`、`SHA256SUMS`。  
不含 `coeff.dat`。版本名 `YYYYMMDD-HHMM` 或带单字母后缀。  
`site.json`：`schema=canal.site/v1`；`site_id` 为 `^[a-z0-9-]{1,32}$`；`camera` 宽高 fps；`piv.grid_points` = grid 行数。

GRP 首行 `GRP V2.0 <W> <H>`。`img_ref` 末行 `ni nj`（高、宽）。  
`X = xmin + 列×分辨率`，`Y = ymin + 行×分辨率`。

## CSV

```text
frame_id,t_capture,x,y,us,vs,w_corr,corr_raw,camera_id
```

UTF-8 无 BOM，LF。`x,y` 为局部正交米。`corr_raw ≤ -98` 时 `w_corr` 为 0。数据源优先 `vel_real`。

## 测区四角

顺序 SW → SE → NE → NW。投影为 CGCS2000 高斯-克吕格；默认轴序 X 东、Y 北（可切换 X 北、Y 东）。局部坐标（X=E−E0、Y=N−N0）导出时填原点 E0/N0，由 `RoiExporter` 自动加回。

手簿 CSV 列序、过滤规则与 GRP 草稿格式见 [docs/定标与手簿CSV.md](定标与手簿CSV.md)。
